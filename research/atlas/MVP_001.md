# Atlas Micro-Library MVP 001

**Status:** executable prototype

Atlas now has a minimal separation between a durable **Library** and an active **Librarian**.

The seed library contains three concept records:
- Correction Is Survivable
- Reconstruction Is Not Prescription
- Relation as Part of the Codec

The Librarian currently supports four operations:
- FIND — locate candidate concept records.
- TRACE — expose provenance, decompression path, and cliffs.
- RECONSTRUCT — return source meaning with assumptions and decoder prerequisites visible.
- TRANSLATE — prepare a provisional transfer packet for a new context.

The code also records whether a new reading is a reconstruction, compatible extension, contextual translation, transformation, contradiction, or new construction. These labels describe provenance rather than permission.

Run examples:

    python -m code.atlas_demo find "shared context codec"
    python -m code.atlas_demo trace relation-as-codec
    python -m code.atlas_demo reconstruct reconstruction-not-prescription
    python -m code.atlas_demo translate relation-as-codec "cross-cultural scholarship"

The next build target is a source-rich specimen with separate layers for source text, translation, historical reconstruction, interpretation, and later transformation. The goal is to test whether the Librarian can state not only an answer, but what kind of answer it is giving and how to return to its sources.
