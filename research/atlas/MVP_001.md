# Atlas Micro-Library MVP 001

**Status:** executable prototype with Source Layers v0.2

Atlas has a minimal separation between a durable **Library** and an active **Librarian**.

The seed library now includes:
- Correction Is Survivable
- Reconstruction Is Not Prescription
- Relation as Part of the Codec
- Pauline Permission, Benefit, Mastery, and Building Up

The Librarian supports five operations:
- FIND — locate candidate concept records.
- TRACE — expose provenance, decompression path, and cliffs.
- RECONSTRUCT — return source meaning with assumptions and decoder prerequisites visible.
- LAYERS — inspect source, translation, reconstruction, interpretation, transformation, and correction separately.
- TRANSLATE — prepare a provisional transfer packet for a new context.

The code also records whether a new reading is a reconstruction, compatible extension, contextual translation, transformation, contradiction, or new construction. These labels describe provenance rather than permission.

Run examples:

    python -m code.atlas_demo find "shared context codec"
    python -m code.atlas_demo trace relation-as-codec
    python -m code.atlas_demo reconstruct reconstruction-not-prescription
    python -m code.atlas_demo layers paul-all-things-lawful
    python -m code.atlas_demo layers paul-all-things-lawful --type source_text
    python -m code.atlas_demo layers paul-all-things-lawful --type transformation
    python -m code.atlas_demo translate relation-as-codec "cross-cultural scholarship"

## Source Layers v0.2

The first serious source-rich specimen showed that one flat source-reconstruction field was not enough.

Atlas now preserves typed layers:

    source_text
    translation
    lexical_note
    historical_reconstruction
    scholarly_interpretation
    reader_interpretation
    transformation
    source_correction

See [Schema v0.2 — Source Layers](SCHEMA_V0_2_SOURCE_LAYERS.md).

## Current lesson

The Pauline specimen demonstrated that Atlas can preserve a later working compression such as “constructive” while also reopening the richer path:

    1 Corinthians 6:12
      -> permission + benefit + mastery

    1 Corinthians 10:23
      -> permission + benefit + building up

    later relational compression
      -> constructive

The source, translation, interpretation, and later transformation remain inspectably separate.

The next build target should test a second source-rich corpus from a **different decoder environment**—ideally one where cultural or linguistic assumptions differ enough to stress the assumption-envelope and decoder-preparation parts of Atlas.
