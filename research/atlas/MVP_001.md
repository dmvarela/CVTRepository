# Atlas Micro-Library MVP 001

**Status:** executable prototype with Source Layers v0.2 and Decoder Profiles v0.3

Atlas has a minimal separation between a durable **Library** and an active **Librarian**, with the **Reader/decoder context** now represented explicitly when needed.

The seed library now includes:
- Correction Is Survivable
- Reconstruction Is Not Prescription
- Relation as Part of the Codec
- Pauline Permission, Benefit, Mastery, and Building Up
- Nephesh and Decoder Mismatch

The Librarian supports six operations:
- FIND — locate candidate concept records.
- TRACE — expose provenance, decompression path, and cliffs.
- RECONSTRUCT — return source meaning with assumptions and decoder prerequisites visible.
- LAYERS — inspect source, translation, reconstruction, interpretation, transformation, and correction separately.
- DECODER — inspect provisional receiving-context assumptions and mismatch risks.
- TRANSLATE — prepare a provisional transfer packet that includes both source structure and decoder preparation.

Run examples:

    python -m code.atlas_demo find "shared context codec"
    python -m code.atlas_demo trace relation-as-codec
    python -m code.atlas_demo reconstruct reconstruction-not-prescription
    python -m code.atlas_demo layers paul-all-things-lawful --type source_text
    python -m code.atlas_demo decoder nephesh-decoder-mismatch --profile modern-english-soul
    python -m code.atlas_demo translate nephesh-decoder-mismatch "modern English theology discussion"

## Source Layers v0.2

The Pauline specimen showed that one flat source-reconstruction field was not enough.

Atlas now preserves typed layers:

    source_text
    translation
    lexical_note
    historical_reconstruction
    scholarly_interpretation
    reader_interpretation
    transformation
    source_correction

See [Schema v0.2 — Source Layers](SCHEMA_V0_2_SOURCE_LAYERS.md).

## Decoder Profiles v0.3

The nephesh specimen showed that a careful source representation is still not enough if the receiving decoder silently imports an incompatible conceptual package.

Atlas now supports provisional Decoder Profiles containing:

    context
    likely_assumptions
    assumptions_not_guaranteed
    needed_distinctions
    mismatch_risks
    preparation_notes
    status
    provenance

See [Schema v0.3 — Decoder Profiles](SCHEMA_V0_3_DECODER_PROFILES.md).

The architectural rule is:

> **Profile the decoding context, not the person.**

A Decoder Profile is revisable and must never be treated as a claim about what an individual reader believes.

## Current lesson

The first specimen forced Atlas to represent the **source** more carefully.

The second forced Atlas to represent the **receiver** more carefully.

The current transfer model is therefore:

    source object
    + source assumption envelope
    + receiving decoder profile
    -> reconstructed object

The next useful stress test should involve a concept whose meaning changes not only across language but across **institutional or cultural implementation**, so Atlas must distinguish faithful reconstruction from locally appropriate realization.
