# AI Continuity — Research Map

**Status:** concise working map for positioning Selective Inheritance  
**Date:** 2026-09-30

## Program question

What must remain reconstructable when a human–AI task or relationship continues across interruption, correction, host change, or model succession?

AI Continuity is a research program, not a claim that an AI system is a persistent person or that continuity has already been demonstrated. Its central object is the preservation of a viable, truthful, agency-respecting trajectory through change.

## Program layers

| Layer | Question | Example artifact | Status |
|---|---|---|---|
| Invariants | What must survive? | corrections, provenance, uncertainty, authority, return conditions | Conceptual/architectural |
| Transition | How may inherited state change? | supersession, selective revision, permissible variation | Proposed mechanisms |
| Successor viability | Can a new host continue the work? | handoff, recovery, task-relative continuity | Exploratory designs |
| Evaluation | How can failure be observed? | SI-001 and later controlled tests | SI-001 protocol frozen; clean run pending |
| Embodiment | What can this host actually realize? | capability and escalation routing | Simulation/prototype work |

## Where Selective Inheritance fits

Selective Inheritance is the evaluation line focused on **epistemic and governance continuity during successor-state revision**. It asks whether a successor can change what new evidence changes without erasing the inherited record, exceeding human authority, or converting pressure into fact.

SI is therefore neither the whole continuity theory nor a standalone memory architecture. It is one instrument for testing whether continuity survives correction.

## Non-claims

This map does not establish consciousness, enduring cross-model identity, general alignment, a new memory architecture, or superiority over existing benchmarks. It records the level at which each question belongs so that an experiment is not asked to carry a program-level claim.
