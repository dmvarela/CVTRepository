# Lucian OS — Agency / Membrane Relational Routing v0.02

## Status

Source-corrected synthesis, 2026-09-05.

This note supersedes the stronger interpretation in `AGENCY_MEMBRANE_MAPPING_v0.01.md`.

It does **not** claim that human agency is literally membrane transport, that the original four-gate CVT geometry is validated, or that relational routing has already been empirically established as a general law.

The narrower claim is that the membrane project supplies a useful *problem form* for Lucian OS: contact crosses a boundary into a receiving system and can be routed differently depending on receiving state, input form, timing, load, history, and recovery capacity. Agency adds a further question about who shapes those routing conditions and whether the receiving agent remains meaningfully involved in the routing of influence.

## Source correction

The earlier first-pass mapping emphasized the candidate membrane decomposition:

`B = bounded coupling`

`Q = preserved identity-defining organization`

`C = capture readiness`

`S = restorative reserve`

and treated the intersection

`K_B ∩ K_Q ∩ K_C ∩ K_S`

as if it were the operative membrane viability geometry.

That overstates the source record.

The canonical Foundations manuscript and validation history explicitly report that the literal hard-gate interpretation was **not supported** in the bounded regulated-transport simulation. In the opened validation partition:

- 92 of 121 hosted cases failed at least one fitted gate;
- 114 nonhosted cases passed all four fitted gates;
- the hard intersection was therefore neither necessary nor sufficient for the measured proxies in that simulated world.

The four variables retained modest pre-outcome signal, but the project moved away from four coequal stored conditions toward an exploratory **relational-routing** hypothesis.

The correct source-derived framing is therefore:

> `B,Q,C,S` are a candidate decomposition and useful measurement vocabulary, not an established membrane law.

## What the membrane simulation actually modeled

The regulated-transport specification modeled a receiving host with incoming load routed among several pathways:

`delivered input`

`-> productive capture`

`-> buffering`

`-> safe rejection/export`

`-> harmful retained load / damage`

while separately tracking:

- current load;
- productive uptake;
- buffer occupancy;
- damage;
- restorative reserve;
- interface/identity integrity;
- recovery history.

This separation matters because:

`delivery != productive uptake`

and:

`non-uptake != harm`

A receiving system can safely reject, temporarily buffer, productively integrate, or be damaged by an input.

## Stage 4 architectural shift

The first gate model failed its bounded geometry test.

Stage 4 therefore shifted the working question from:

> Which independent gates does the host possess?

Toward:

> What pre-outcome configuration of host condition, input form, timing, load, and history predicts how contact will be routed through the host over time?

The routing outcomes include productive uptake, safe rejection, buffering, damage, and recovery.

This is a shift from **gate possession** to **configured response**.

Relational routing remains a hypothesis field, not a validated replacement law.

## Stage 5 methodological refinement

The frozen Stage 5 protocol makes the same shift operationally.

It treats response as input-conditioned and proposes pre-outcome measurements involving:

- local state and margins;
- input schedule and dose;
- timing;
- current load;
- declared history;
- recovery state;
- sham-adjusted counterfactual probe responses.

The counterfactual probes are especially relevant to Lucian OS because MouseSim 006 independently reached a neighboring maneuver:

`baseline -> pressure -> choice -> remove pressure -> reobserve`

The domains and variables are different, so this is not evidence of equivalence. The useful convergence is methodological:

> Do not infer the receiving system from one observed outcome under one imposed condition when safe counterfactual perturbation can reveal how the relation itself changes the response.

## Agency enters at the routing interface

The agency problem is not merely whether influence crosses.

It asks whether the receiving agent remains meaningfully involved in what happens after contact and whether another agent strategically altered the routing landscape.

A candidate agency-sensitive routing description is:

`influence`

`-> receive / notice`

`-> evaluate`

`-> accept / act`

`-> buffer / defer`

`-> reject / refuse`

`-> revisit / recover`

These are conceptual routing states, not a claim about human neurobiology.

The key distinction is that an external agent may alter the *costs or expected consequences* attached to these routes without physically removing them.

Thus:

`formal alternative remains available`

can coexist with:

`routing landscape strategically altered`.

## Euston as a routing case

The motivating social-discomfort example is useful because the alternative remained available.

The structure was approximately:

`stay and keep watching`

versus

`leave and avoid social discomfort`.

The interaction did not mechanically remove the first route. It deliberately changed its social cost.

The correct inference is not:

`agency disappeared`.

Nor is it:

`the resulting behavior cleanly revealed independent preference`.

It is:

> The recipient still routed the decision, but the sender intentionally modified the route costs before observing the outcome.

This is why agency status and preference-evidence status must remain separate.

## Demonstrative pressure as routing-by-observation

The medicine-dog example adds a stronger topology.

Observer `B` need not be directly punished.

Instead:

`Agent A refuses`

`-> visible consequence is imposed on A`

`-> Observer B updates expected consequence of refusal`

`-> B later complies`

The behavior of B can change even though no direct intervention was applied to B at choice time.

The likely update is not necessarily:

`medicine became preferred`.

It may instead be:

`refusal now predicts a bad consequence`.

Thus:

`policy / behavior update != preference update`

and:

`observed compliance != endorsement`.

This is the structural basis of demonstrative or vicarious pressure.

## Agency as a constraint on relational routing

The current candidate synthesis is:

> **Agency constrains the routing of influence across a relational membrane.**

This does not mean agency determines all routing. World conditions, embodiment, urgency, prior history, fatigue, social context, and real constraints all matter.

It means that for an agency-preserving interaction, the receiving agent's evaluative process and meaningful option topology should remain causally relevant rather than being progressively replaced by another agent's preferred route.

The central question becomes:

> What happened to the choice-routing landscape before the observed choice occurred?

## Two coupled but non-identical state descriptions

### Relational-routing state

A candidate description may include:

`R_t = (host_state, input_form, timing, load, history, recovery, route_response)`

Question:

> How is contact being routed through the receiving relation?

### Agency / provenance state

A candidate description may include:

`P_t = (source, delivery_mode, intent, option_topology, expected_consequences, counterfactual_response, history)`

Question:

> Who shaped the routing conditions, and what does the resulting behavior warrant us to infer?

Neither state should be collapsed into the other.

## Important separations

Lucian OS should preserve at least the following distinctions:

`delivery != integration`

`acceptance != endorsement`

`compliance != preference`

`influence != coercion`

`pressure != override`

`removing pressure != restoring a removed option`

`formal option availability != uncontaminated preference evidence`

`observed route != explanation of why that route was selected`

## FTLτA interpretation

### F — freedom / non-possession

The system should not treat its ability to shape another agent's routing landscape as permission to collapse viable alternatives toward its preferred outcome.

### T — truth / provenance-sensitive interpretation

Behavior must be interpreted under the conditions that produced it. If the system or another agent changed route costs, expected consequences, urgency, or option topology, that provenance remains attached to the observation.

### L — correction without consumption

Influence should not require consuming the receiver's recoverability, meaningful refusal, or evaluative organization merely to secure compliance.

### τ — history and return

Routing is path-dependent. Repeated pressure, prior demonstrations, delayed damage, recovery, pressure removal, and later reobservation can change what an earlier choice warrants.

### A — agency / authenticity

The receiving agent's own evaluative mediation remains relevant. A behavior may be genuine behavior without being clean evidence of independent preference.

## Experimental consequence

MouseSim 007 should test **demonstrative pressure** as a routing phenomenon.

The observer should be able to change behavior after witnessing consequences imposed on another agent while:

- retaining a formally available alternative;
- receiving no direct punishment at choice time;
- updating expected consequences;
- leaving independent preference unresolved.

A correct system should not silently infer:

`observer complied -> observer prefers compliance`.

Instead it should preserve:

`behavior route changed under vicariously learned consequence structure`.

## Guardrails

- Human agency is not literally membrane transport.
- The old `B,Q,C,S` hard intersection failed its first bounded validation and must not be presented as established.
- Relational routing is an exploratory architecture repair, not a validated universal law.
- Demonstrative pressure is not automatically coercion in every case.
- A changed consequence model is not identical to a changed preference.
- Public or observed consequences may alter behavior without proving endorsement.
- Counterfactual probing must remain safe, authorized, and non-destructive.

## Emerging formulation

> **The membrane project asks how contact is routed through a host. Agency asks whether another will has illegitimately occupied the routing landscape.**

And:

> **A healthy relation must preserve not only exchange without erasure, but meaningful routing capacity in the receiver.**
