# Treatise Paper Map — Working Crosswalk

This file maps current manuscripts and active research threads onto the treatise architecture without changing their canonical paths, publication status, or disciplinary boundaries.

The purpose is architectural: papers remain bounded scholarly extracts; the treatise records how their objects connect.

## Core architecture

`relations -> formation -> capability accumulation -> graduation -> generativity -> accretion -> reproductive closure -> robustness -> adaptive embeddedness`

The treatise also contains cross-cutting layers that condition these transitions: boundaries, authority, recoverability, agency, backcasting, and normative admissibility.

## A. Development-economics sub-spine

### Paper F — Staged Coupled Linkages / Network-Conditioned Graduation

**Primary location in architecture:**

`formation -> capability accumulation -> graduation -> generativity`

**Current object:** How an initially nonviable productive relation becomes active, converts operation into durable capability, survives withdrawal of extraordinary support, and changes the graduation conditions of later relations.

**Current core variables / objects:**

- `q_(e,t)` — accumulated relation-specific productive capability;
- `Lambda_e(Omega_t)` — conversion rate from current operation into durable capability;
- `delta_e` — capability loss / decay;
- `q*_e` — unsupported viability threshold;
- `gamma_e = Lambda_e / (delta_e q*_e)` — reduced-form graduation margin;
- graduation frontier `G_t = {e : gamma_(e,t) > 1}`;
- external productive accessibility / effective productive distance;
- supported activation vs. genuine graduation;
- secondary generativity: whether a graduated relation raises `Lambda_f`, lowers `q*_f`, reduces activation burdens, or otherwise improves later graduation conditions.

**Strongest current formal seam:** network-conditioned graduation / minimum support duration under complementarity.

**Open seam:** define unsupported dependency closure so a relation cannot falsely graduate by relying on a permanently supported neighbor.

**Literature discipline:** Big Push, Hirschman linkages, infant-industry / learning-by-doing, supermodular / monotone coordination, economic complexity / product space, GVCs, endogenous network formation, export discipline.

**Status:** active conceptual/formal development; no canonical manuscript path should be inferred from this map until registered separately.

### Paper E — Theory of Reproductive Accretion

**Primary location in architecture:**

`accretion -> reproductive closure -> robustness`

**Current object:** When separately organized subcritical components become a higher-order reproductive system, how newcomers accrete into an existing reproductive core, and why reproductive strength differs from robustness.

**Core block object:**

`B(alpha,beta) = [[A, alpha P], [beta Q, D]]`, with `rho(A)<1`, `rho(D)<1`.

Define

`T = (I-A)^(-1) P (I-D)^(-1) Q`

and

`Gamma = rho(T)`.

The threshold is

`rho(B) <,=,> 1  iff  alpha beta Gamma <,=,> 1`.

**Interpretive distinction:**

> A chain transmits. Reciprocal coupling closes. Sufficient round-trip gain reproduces. Reproduction does not guarantee robustness.

**Robustness result / construction:** bounded local degree, fixed Perron margin, nonvanishing edge weights, and exponentially many cycles can coexist with one-edge failure of reproduction.

**Open seam:** formal map from Paper F's graduated / generative linkage state into Paper E's weighted nonnegative network object.

**Status:** mathematically mature relative to Paper F; inherited positive-systems / Perron / M-matrix machinery must remain clearly credited.

## F. Current unresolved bridges

1. **F -> E composability** — map graduated / generative productive relations into the weighted network object used for reproductive closure and robustness.
2. **Graduation dependency closure** — prevent false graduation through permanently supported neighbors or hidden policy channels.
3. **Endogenous conversion rate** — determine `Lambda_e(Omega_t)` rather than treating it as primitive.
4. **Scarcity and competition** — add negative interactions without silently destroying the monotone baseline model; likely treat pure complementarity as the baseline and scarcity / displacement as an extension.
5. **Adaptive embeddedness** — characterize when external productive closure can survive or reroute after partner / market / supplier changes.
6. **Empirical diagnostics** — distinguish activation, capability accumulation, graduation, generativity, closure, and robustness in observable data.
7. **Terminology / literature** — maintain the distinction between inherited results, proposed mechanisms, explicit constructions, empirical hypotheses, and cross-domain analogies.

## G. Working rule for future research

When a new idea appears, do not first ask which paper owns it.

Ask:

1. Which transition in the architecture does it affect?
2. Does it modify the general mechanism or instantiate it in one domain?
3. What is its epistemic status: proved result, inherited mathematics, formal conjecture, proposed mechanism, empirical hypothesis, analogy, or open question?
4. Which bounded paper, if any, is the right place to earn the claim rigorously?

The treatise is the map. The papers are the pressure-tested extracts.
